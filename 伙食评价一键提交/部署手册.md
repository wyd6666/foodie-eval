# 部署手册

所有部署方式都在这里。按你的情况挑一种，不用全看。

---

## 一、有哪几种，怎么选

| 方式 | 适合谁 | 难度 | 别人能访问吗 |
|---|---|---|---|
| **A. Windows 双击** | 就自己一台电脑用 | ★ | 不能 |
| **B. Mac / Linux 命令行** | 自己电脑，喜欢终端 | ★ | 不能 |
| **C. Docker（1Panel / 群晖 / 通用）** | 有 NAS 或服务器 | ★★ | 能（局域网） |
| **D. 服务器直接跑 Python** | 有 Linux 服务器，不想装 Docker | ★★ | 能（局域网） |

**只想自己用** → A 或 B，一分钟搞定。
**想给同事用 / 手机也能交** → C 或 D。

---

## 二、方式 A：Windows 双击

### 1. 装 Python

去 https://www.python.org/downloads/ 下最新版，安装时**务必勾选 `Add Python to PATH`**。

验证：按 `Win+R` 输 `cmd`，打 `python --version`，能出版本号就成。

### 2. 解压

把 zip 解压到任意目录，比如 `D:\伙食评价`。

### 3. 双击

| 双击哪个 | 干什么 |
|---|---|
| `网页版.bat` | 打开浏览器，页面上粘名单点两下 |
| `一键评价.bat` | 全自动：装依赖 → 找名单 → 预演 → 等你按回车才真交 |
| `自检.bat` | 出问题时先跑这个 |

第一次跑会问一次服务器地址（手机上 App 登录页那个），问完就记住了。

### 4. 名单放哪

解压目录下放一个 `账号密码.txt`，一行一个人，三种写法都认：

```
姓名 账号 密码
李四=370101199001011235=密码
370101199001011236,密码,王五
```

也可以直接把文件拖到网页的虚线框里。

### 5. 关闭

**用完把黑色窗口关掉就行**，服务就停了，没有后台残留。

## 三、方式 B：Mac / Linux 本机

```bash
cd 解压后的目录

./网页版.sh                 # 打开网页版
./一键评价.sh               # 命令行全自动
./自检.sh                   # 环境自检
```

第一次可能要给它加执行权限：

```bash
chmod +x *.sh
```

依赖会自动装。想手动装：

```bash
python3 -m venv .venv
.venv/bin/pip install -i https://pypi.tuna.tsinghua.edu.cn/simple requests
```

> 只装 `requests` 就够。`cryptography` 是可选的（装了算 AES 快 1 毫秒，不装用内置实现）。

## 四、方式 C：Docker

1Panel、群晖 Container Manager、宝塔、纯 docker 都通用。

### 1. 准备文件

在一个目录里准备这几样（从发布包里拿）：

```
hqhs-eval/
├── Dockerfile
├── docker-compose.lan.yml
├── eval_config.json
├── web/
│   ├── server.py
│   ├── index.html
│   └── requirements.txt
└── scripts/
    ├── hqhs_eval.py
    ├── aes_pure.py
    └── import_accounts.py
```

改 `eval_config.json` 的 `host`：

```json
{
  "scheme": "http",
  "host": "sd.example.gov.cn",
  "presets": ["sd.example.gov.cn"],
  "strategy": "max",
  "timeout": 15,
  "log_dir": "out"
}
```

> 就是手机上 App 登录页填的地址，**不要带 `http://`，不要带 `/api/`**。

### 2. 创建容器

**1Panel**：容器 → 编排 → 创建编排 → 名称 `hqhs-eval` → 来源选「粘贴内容」→ 把 `docker-compose.lan.yml` 整个贴进去 → 改一行 `HQHS_PASSWORD` → 确认。

**群晖**：Container Manager → 项目 → 新增 → 选这个目录 → 它会自己读 `docker-compose.lan.yml`。

**纯 docker**：

```bash
cd hqhs-eval
docker compose -f docker-compose.lan.yml up -d --build
```

第一次要构建镜像，2~5 分钟。

### 3. 放行端口

- 1Panel：主机 → 防火墙 → 端口规则 → 加 `8080/TCP`
- 群晖：控制面板 → 安全性 → 防火墙 → 允许 8080
- 云服务器：还要去**控制台安全组**加一条入站规则

### 4. 访问

```
http://服务器内网IP:8080
```

例：`http://192.168.1.100:8080`

## 五、方式 D：服务器上不用 Docker

这个应用只需要一个 Python 包，比拉 Docker 镜像省事得多。

### 1. 装依赖

```bash
cd /opt/hqhs-eval

apt install -y python3 python3-venv
python3 -m venv .venv
.venv/bin/pip install -i https://pypi.tuna.tsinghua.edu.cn/simple requests
```

### 2. 先前台试跑

```bash
.venv/bin/python web/server.py --host 0.0.0.0 --port 8080 --password '你的密码'
```

看到这个就说明成了：

```
========================================================
 伙食评价 · 网页版
========================================================
 打开: http://127.0.0.1:8080
 服务器地址: sd.example.gov.cn
 版本    : 5.7.3
 访问密码: 静态密码（登录后 12 小时免登录）
```

按 Ctrl+C 停掉，接着做开机自启。

### 3. 开机自启（systemd）

```bash
cat > /etc/systemd/system/hqhs-eval.service <<'EOF'
[Unit]
Description=hqhs eval web
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/hqhs-eval
ExecStart=/opt/hqhs-eval/.venv/bin/python web/server.py --host 0.0.0.0 --port 8080 --password 你的密码
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable --now hqhs-eval
systemctl status hqhs-eval
```

常用操作：

```bash
systemctl restart hqhs-eval     # 重启
systemctl stop hqhs-eval        # 停
journalctl -u hqhs-eval -f      # 看实时日志
```

### 4. 放行端口

```bash
# ufw
ufw allow 8080/tcp

# firewalld
firewall-cmd --add-port=8080/tcp --permanent && firewall-cmd --reload
```

## 六、访问密码怎么配

有**两种**，可以只用一种，也可以都用。

### 静态密码

在 `docker-compose.lan.yml` 里：

```yaml
    environment:
      HQHS_PASSWORD: "改成你的密码"
```

方式 D（不用 Docker）则是命令行参数 `--password`。

### 动态密码（TOTP）

手机上装 **Google Authenticator**，30 秒变一次的 6 位码。

**① 生成密钥**

```bash
# Docker
docker exec hqhs-eval python /app/web/server.py --gen-totp

# 方式 D
.venv/bin/python web/server.py --gen-totp
```

```
新的动态码密钥（填到 eval_config.json 的 totp_secret）：

  CKIPUCGHOAUDU443LCNZPNGEU2CFXJ2R

用 Authenticator 添加这个链接：

  otpauth://totp/hqhs-eval:hqhs-eval?secret=CKIP...&issuer=hqhs-eval&period=30&digits=6
```

**② 填进 `eval_config.json`**

```json
{
  "totp_secret": "CKIPUCGHOAUDU443LCNZPNGEU2CFXJ2R",
  "totp_window": 1,
  "auth_mode": ""
}
```

**③ 重启容器**（方式 D 就 `systemctl restart hqhs-eval`）

### 三种模式

| `auth_mode` | 登录要什么 |
|---|---|
| `""` 留空 | 有 `totp_secret` 就**只认动态码**；没有就用静态密码 |
| `"totp"` | 只认动态码 |
| `"password"` | 只认静态密码 |
| `"both"` | 两个都认 |

### 常见组合

**只要固定密码**

```yaml
HQHS_PASSWORD: "我的密码"
```
```json
"totp_secret": "", "auth_mode": ""
```

**只要动态码**

```yaml
# HQHS_PASSWORD 注释掉
```
```json
"totp_secret": "CKIP...", "auth_mode": ""
```

**两个都要**

```yaml
HQHS_PASSWORD: "备用密码"
```
```json
"totp_secret": "CKIP...", "auth_mode": "both"
```

## 七、配置文件说明

`eval_config.json` 每一项：

| 字段 | 干什么 | 例子 |
|---|---|---|
| `host` | 评价服务器地址 | `sd.example.gov.cn` |
| `scheme` | 用 http 还是 https | `http` |
| `presets` | 常用地址，页面上显示成胶囊 | `["sd.example.gov.cn"]` |
| `strategy` | 评分策略，`max` = 全给满分 | `max` |
| `timeout` | 单次请求超时（秒） | `15` |
| `log_dir` | 日志目录 | `out` |
| `totp_secret` | 动态码密钥，留空则不用 | `CKIP...` |
| `totp_window` | 动态码容差（1 = ±30 秒） | `1` |
| `auth_mode` | 认证方式 | `""` / `totp` / `password` / `both` |

**改完不用重建镜像**，这个文件是挂载进去的：

```bash
docker restart hqhs-eval          # Docker
systemctl restart hqhs-eval       # 方式 D
```

`host` 项改完刷新页面就生效，连重启都不用。

## 八、更新与回退

### 更新

```bash
# Docker
cd /opt/1panel/apps/hqhs/hqhs-eval
bash 重建.sh

# 方式 D
覆盖 web/ 和 scripts/ 两个目录后
systemctl restart hqhs-eval
```

**`docker compose up -d` 不会重建镜像** —— 镜像已经存在就直接用旧的。必须 `build`：

```bash
docker compose -f docker-compose.lan.yml build --no-cache
docker compose -f docker-compose.lan.yml up -d --force-recreate
```

包里的 `重建.sh` 就是做这两步的。

### 确认更新成功

页面标题旁：

| 显示 | 含义 |
|---|---|
| `v5.7.3 · AES:cryptography` | ✅ 好了 |
| `v5.7.3 · … · 前端 5.7.3 不一致` **红** | 后端新了前端旧，只覆盖了一半文件 |
| 版本号没变 | 镜像没换，跑 `重建.sh` |

### 回退

```bash
bash 恢复版本.sh              # 看有哪些版本
bash 恢复版本.sh v5.7.0       # 回到 v5.7.0
bash 重建.sh                  # 重新部署
```

每次打包都会自动存一份源码快照到 `versions/vX.Y.Z/`。

## 九、排错

### 打开是 502 / 拒绝连接

```bash
docker ps | grep hqhs-eval            # 容器在跑吗
docker logs --tail 30 hqhs-eval       # 看报错
curl -s http://127.0.0.1:8080/api/state   # 本机通吗
```

本机通、外面不通 → 防火墙或端口绑定问题。

### 版本号一直不变

`docker compose up -d` 不会重建镜像。跑 `重建.sh`，或者：

```bash
docker compose -f docker-compose.lan.yml build --no-cache
docker compose -f docker-compose.lan.yml up -d --force-recreate
docker exec hqhs-eval grep VERSION /app/web/server.py
```

### 提示「配置文件只读」

容器内 `/app/eval_config.json` 是单文件挂载点，不能 rename。v5.3 起已改成原地覆盖写，如果还提示：

```bash
sudo chown 1000:1000 /opt/1panel/apps/hqhs/hqhs-eval/eval_config.json
```

### 日志里 Permission denied

```bash
docker exec -u root hqhs-eval chown -R 1000:1000 /app/out
```

v5.6 起即使不修也会自动退到容器内 `/app/.local-out`（提交照常成功，只是容器重建后当天台账会丢）。

### 镜像拉不下来

```bash
bash 准备镜像.sh
```

它会试几个国内源，拉下来打成 `python:3.11-slim` 标签，之后构建就不联网了。

或者干脆走方式 D，不碰 Docker。

### 页面能开但按钮没反应

按 F12 看 Console 有没有红字，或者页面顶部有红条会直接说原因。

### 所有人都被锁 10 分钟

说明后端的限流把所有人当成同一个 IP。局域网直连不该有 `HQHS_TRUST_PROXY`，删掉这个环境变量。

### 提交成功但显示失败

v5.7 起日志写不进去不会影响业务了。如果还出现，看日志里有没有 `[警告]` 开头的行为。

### 手机上看不到「状态」列

v5.7.1 已修（之前误把状态列藏了）。旧版本请更新。

## 十、日常运维

### 看日志

```bash
docker logs --tail 50 hqhs-eval                              # 程序输出
cat ./data/web_$(date +%Y%m%d).log                           # 运行日志
cat ./data/submitted.json                                    # 当天台账
```

方式 D 的话路径是 `/opt/hqhs-eval/out/`。

### 备份台账

1Panel → 计划任务 → 备份目录 → `./data` → 每天。

方式 D：

```bash
echo "0 23 * * * cp /opt/hqhs-eval/out/submitted.json /backup/submitted-$(date +\%F).json" | crontab -
```

### 加人 / 删人

```bash
bash run.sh list                     # 看名单（密码打码）
bash run.sh add 姓名 账号 密码       # 加
bash run.sh del 账号                 # 删
bash run.sh addfile 新人.txt         # 批量加
bash run.sh list --check             # 顺便验密码
```

Windows 上双击 `win\7-加人.bat` 等。

## 附：文件都是干什么的

| 文件 | 作用 |
|---|---|
| `web/server.py` | 网页后端 |
| `web/index.html` | 页面（单文件，HTML+CSS+JS 全在里面） |
| `scripts/hqhs_eval.py` | 核心：登录、取模板、填分、提交 |
| `scripts/aes_pure.py` | 纯 Python AES（没装 cryptography 时用） |
| `scripts/import_accounts.py` | 名单解析 |
| `scripts/hqhs_batch.py` | 多账号批量 |
| `scripts/onekey.py` | 一键编排（`一键评价.bat` 调它） |
| `scripts/manage_accounts.py` | 加人删人 |
| `scripts/selfcheck.py` | 环境自检 |
| `docker-compose.lan.yml` | Docker 编排（只有一个） |
| `Dockerfile` | 镜像定义 |
| `eval_config.json` | 配置 |
| `重建.sh` / `重建.bat` | 更新时用 |
| `强制更新.sh` | 版本卡住时用，清一切重来 |
| `准备镜像.sh` | 拉不到镜像时用 |
| `恢复版本.sh` | 回退到历史版本 |
